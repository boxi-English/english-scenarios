# One conditional, two intentions

The speaker is explaining a past decision that did not happen. Before reading the explanation, predict which sentence matches that meaning.

1. If I know earlier, I call you.
2. If I had known earlier, I would have called you.
3. If I knew earlier, I will call you.

The target is **2**. The condition uses `had known` and the consequence uses `would have called`. Both refer to a past situation that did not happen. The sentence is useful because it explains a missed action, not because it is a rule to memorize without context.

## Produce

Write a new sentence about a warning you did not see. Keep the same meaning pattern.

## Feedback

Check three dimensions separately:

- **Form:** did the condition and consequence use the past counterfactual pattern?
- **Time reference:** do both parts point to a situation before now?
- **Communicative fit:** does the sentence explain a missed or different past result?

Revise one sentence, then answer the transfer prompt: `If I had seen the warning, ...`
